How to get a useful result

Good analysis begins with a clear question. These steps keep the result understandable and traceable.

Before you begin

Know the source and scope

Check who produced the data, when it was collected, which places or groups it covers, and whether values are complete.

While exploring

Choose a comparison that fits

Use a meaningful period or category. Keep scales and units visible, and distinguish missing values from zero.

When sharing

Make the takeaway explicit

Write what changed, where and when. Avoid implying that a trend proves a cause unless the data supports it.

One connected workflow

01 · PREPARECheck the data before analysis

Review column names and value types. Look for missing entries, duplicate rows, inconsistent units or date formats.

Keep: the source, covered dates, geographic scope and a note about any corrections.
02 · ANALYZEExplore a clear question

Compare groups or periods, inspect unusual values, and choose a chart that fits the question and the kind of measure.

Check: labels, scales, units, sample size and whether the comparison uses the same definitions.
03 · PRESENTMake the finding understandable

Build a dashboard or report that gives readers the result and enough context to interpret it correctly.

Include: a descriptive title, source, time period, units, key values and a concise takeaway.

How to use an example responsibly

01 · Verify

Check the source and period

Confirm who published the data, which dates and locations it covers, and when it was last updated.

02 · Compare

Use matching measures

Compare like with like. Keep units, geographic scope and time intervals consistent across the chart.

03 · Explain

Show values behind the trend

Pair a chart with the underlying table, define the baseline and state what the data cannot tell you.

Frequently asked questions

Practical answers about choosing data, reading results and preparing a report.

What kind of dataset can I analyze?
A structured table is easiest to work with: one row per observation and one column per measure or category. Check the upload screen for the file formats supported by the current build.
How do I know whether two datasets can be compared?
Check that they use compatible definitions, units, date ranges and geographic coverage. If a measure or collection method changed, call that out before interpreting the difference.
What should I check before interpreting a chart?
Read the title, axis labels, units, period and comparison baseline. Then check the source and whether missing values or changes in coverage could affect the pattern.
Why include the source and period in a report?
They let readers trace where the values came from and understand which time span they describe. Include the publisher, date range, measure and any important limitations.
Does a trend in the chart explain what caused it?
No. A chart can show that values changed or moved together; it does not by itself establish why. Describe the observed pattern and avoid claiming a cause without supporting evidence.
How do I get access or resolve a sign-in problem?
Use the credentials issued for your account. For a new account, a password reset or other access issue, contact the person or organization that provided them.
